# Minimarket_Agile
## Visión del Producto

El proyecto consiste en el desarrollo de un sistema de software ágil, intuitivo y seguro diseñado para optimizar y centralizar las operaciones diarias de un minimarket. La plataforma conectará el Punto de Venta (caja) con el almacén y la administración, permitiendo reducir los tiempos de espera del cliente, evitar la pérdida de mercadería por vencimiento y proporcionar a la gerencia datos financieros exactos en tiempo real para una mejor toma de decisiones.

## Objetivos

Objetivo General: 

Automatizar y registrar el 100% de las transacciones comerciales y movimientos de almacén del minimarket mediante una interfaz de usuario fácil de usar y con baja curva de aprendizaje.

Objetivos Específicos:

Agilizar el proceso de cobro en caja mediante el uso de búsqueda rápida e integración de múltiples métodos de pago.

Garantizar la exactitud del inventario a través de alertas automatizadas de stock mínimo y control estricto de fechas de caducidad.

Centralizar el control financiero facilitando reportes de cierre y cuadre de caja precisos al final de cada turno.

## Alcance

Lo que SÍ incluye:

Módulo de Punto de Venta (POS) con cálculo automático de totales y vueltos.

Gestión de Inventario (ingresos, bajas por merma y alertas de stock).

Administración de Usuarios y Roles (Cajero, Almacenero, Gerencia).

Reportes básicos de flujo de caja e historial de movimientos.

Lo que NO incluye (Fuera del alcance inicial): 

Tienda virtual (E-commerce) o aplicación móvil para clientes.

Sistema de envíos a domicilio (Delivery).

## Perfiles de Usuario

Cajero: 
Responsable de la atención al público, escaneo de productos y recepción de pagos.

Almacenero: 
Encargado de la recepción de pedidos, auditoría física de góndolas y registro de fechas de vencimiento.

Administrador / Gerente:
Responsable de la configuración del sistema, creación de cuentas, arqueo de caja y análisis de las métricas de negocio.
